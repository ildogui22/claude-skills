# {{PROJECT_NAME}} Knowledge

Persistent, agent-maintained project knowledge for Claude Code and Codex. This
repository compiles durable understanding from code, decisions, plans, research,
and operational evidence so each session can orient without reconstructing the
project from scratch.

It does not replace source code, tests, repository instructions, plans, or
original evidence. It is the maintained synthesis and routing layer between
agents and those authorities.

## Start here

1. Read [index.md](index.md).
2. Read [_meta/schema.md](_meta/schema.md) before creating or restructuring pages.
3. Follow [_meta/workflows.md](_meta/workflows.md) when retrieving or maintaining
   knowledge.
4. Follow source records to primary evidence when freshness or precision matters.

Run structural checks with:

```bash
make lint
make status
```
